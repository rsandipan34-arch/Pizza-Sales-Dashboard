
# Pizza Sales Analysis — Power BI Dashboard

An interactive **Pizza Sales Dashboard** built using **Microsoft Power BI** to analyze sales performance, customer preferences, and product-level trends.

The project combines **SQL-based data analysis** with **Power BI visualization**. The key metrics and insights generated in Power BI were cross-checked using SQL queries to ensure accuracy and consistency.

## 📊 Dashboard Highlights

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas per Order
- Daily and Monthly Sales Trends
- Sales by Pizza Category
- Sales by Pizza Size
- Top and Bottom Selling Pizzas
- Revenue and Quantity Analysis
- Interactive filters and slicers

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **SQL** – Data analysis and validation
- **Excel / CSV** – Dataset and data preprocessing

## 🔍 SQL Validation

The key metrics and insights generated in Power BI were independently calculated using **SQL queries** and cross-checked against the dashboard results.

This validation ensured that the calculated KPIs and visualizations in Power BI were consistent with the underlying dataset.
